# Notificações PassaMoz

Quando a operadora confirma um pagamento, o passageiro recebe uma notificação interna com acesso ao bilhete.

Quando a operadora rejeita o pagamento, o passageiro recebe uma notificação informando o motivo operacional e que o lugar foi libertado.

As notificações são persistidas no banco de dados e podem ser marcadas como lidas.
